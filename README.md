# Peter Haoxuan Ge

Academic profile website for Peter Haoxuan Ge.

This is a static HTML and CSS site. `index.html` is the dark academic homepage; its images are in `assets/`. No build step or dependencies are required.

## Hosting

GitHub Pages: publish the `main` branch from `/ (root)`.

## Updating

Edit `index.html` for content, `styles.css` for layout, and `dark.css` for the dark palette. Keep the footer’s last-updated date in sync with content changes.
